Web-only Aurebesh (and closely related) fonts in WOFF2 format.

These files are browser/web font builds. They work in this app and can be
downloaded for web embedding, but they are not desktop installable OTF/TTF
packages.

Source mirror: https://github.com/Taminoful/aurebesh-font-pipeline
Original designers/foundries are credited in the app Fonts table.
