# IDC Hesperapis

Deseret Alphabet typeface reproducing the 1868–69 Russell Bros. type used in the Deseret primers and the 1869 Book of Mormon.

This is the current `Hesperapis-Regular` release from [sigilante/idc-hesperapis](https://github.com/sigilante/idc-hesperapis). It covers the 40 capital and 40 small Deseret letters (U+10400–U+1044F) plus figures and punctuation.
